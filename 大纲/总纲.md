# 总纲

## 故事一句话
理工男陈默在乌蒙圈停更灾难中赴日创业，用技术突破日本商业壁垒，最终为国内玩家建立合法的跨海通道。

## 创意约束
- **反套路规则**：不走系统爽文/玄幻套路。硬核经营≠无脑装逼，每个爽点都来自现实推导（商业规则的对抗、技术的真实突破、市场的理性博弈）
- **硬约束**：
  - ❌ 不允许魔法/修仙/超能力描写；所有"能力"都是现实硬件/软件技术
  - ❌ 不允许技术教程化；代码/网络细节点到为止，重点是决策与突破
  - ❌ 不允许无脑装逼；每次胜利都要付出代价或经历挫折
  - ✅ 必须有高真实度的行业细节和乌蒙圈沉浸感
  - ✅ 对话必须自然引出设定，不硬塞说明
- **主角缺陷**：不懂商业运营 → 陈默的能力上限是"技术方案"，张凯的能力上限是"商业决策"。两人互补但也互相掣肘，这构成了中期的内部冲突
- **反派镜像**：商业规则本身。日本官方渠道的死板限制、资本跟风者的贪婪、市场压力的残酷——反派不是"坏人"，而是一个压倒性的生态系统

## 核心主线
- **主线目标**：在日本建立温泉机厅 → 拿到合法的日框 → 用技术方案解决国内网络限制 → 为乌蒙圈建立永久的新世代通道
- **主要阻力**：
  1. 商业规则（日本官方只卖给法人，陈默没有店铺资质）
  2. 资金压力（300万在日本房产+机器+运营中快速消耗）
  3. 技术难度（bytelocker加密、AllNet VPN欺骗、网络延迟管理）
  4. 市场竞争（资本跟风开温泉机厅，大多翻车；正版框价格飙升）

## 核心暗线
- **暗线主题**：陈默对乌蒙圈责任感的升华。从"我想买机器" → "我要拯救圈子" → "我是否真的能做到"的心理变化
- **回收节点**：第30-50章（旅馆经营初见成效，冠军代言）、第80-100章（资本翻车，陈默确认自己的方向）、第150-180章（技术突破成功，国内隧道建立）

## 反派分层（概要）
- **小反派（前期）**：日本也力销售部的官僚规则；大阪机厅老板的冷漠；初期的商业规则壁垒
- **中反派（中期）**：跟风开温泉机厅的资本方，虽然初心相同，但因不懂行业而快速翻车，反衬陈默的专业；机厅器材贩子的信息垄断与价格垄断
- **大反派（后期）**：日本官方的AllNet网络监管本身。不是敌人，但限制了自由。陈默的最终胜利是"合法欺骗"——在规则框架内找到漏洞

## 世界观/力量体系简介
- **世界观要点**：
  - 2024年秋，SEGA推出PRiSM世代，用bytelocker加密断掉国内灰产
  - 国内乌蒙圈成为"难民"，玩家开始飞日本打机
  - 日本街机市场面临的真实困境：商用设备只卖法人，市场细分割裂
  - 三河安城：真实地名，新干线小站，1-3分钟到达，隔音好，房价低，天然温泉存在
- **力量体系要点**：
  - 核心不是修仙，而是"信息差+技术差+资本差"的三角竞争
  - 陈默的"金手指"是理工科思维（网络工程、硬件认知）
  - 张凯的"金手指"是商业运营能力
  - 敌手是商业生态本身，需要用"正规方案"突破"不合理规则"

## 复合题材融合
- **主题材 / 副题材**：硬核经营（70%） / 乌蒙圈爽文（30%）
- **融合机制**：经营目标与乌蒙玩家需求紧密绑定；每个经营决策都在解决"停更难民"的真实痛点
- **节奏占比**：前期（1-30章）：困境+探索；中期（31-120章）：经营拓展+市场竞争；后期（121-180章）：技术突破+行业重塑
- **关键冲突与爽点**：
  - 商业规则碰壁 → 迂回策略（买店铺、获得法人资质）
  - 资本翻车 → 技术壁垒确立（陈默的极客精神赢了资本贪心）
  - 网络限制 → 跨海隧道（终极突破）

## 财务约束（故事的真实压力点）
- **启动资金**：300万人民币 = 6000万日元（陈默的全部身家）
- **资金分配**：
  - 旅馆购置：~4000-4500万日元
  - 改造+初期运营：~1500万日元
  - 应急储备：仅剩~500万日元
- **资金压力**：买完旅馆改造后**资金几乎耗尽**，完全依赖后续运营利润。这迫使陈默必须在第31-80章快速转正，否则就要融资（但他很抗拒）
- **后期投入**：国际光纤专线成本2000-5000万日元/年，这可能需要额外融资或靠积累的利润来支撑

## 主角成长线
- **起点状态**：24岁理工男，违背父母期望，有300万启动资金，技术能力强，商业运营为零。消极状态：机厅闲逛、被规则碰壁、依赖冲动决策
- **关键跃迁节点**：
  1. 第6章：坐错车到三河安城，发现旅馆 → 第一次"商业敏感"闪现
  2. 第12章：老板同意卖旅馆 → 决心从"想法"变成"行动"
  3. 第45章：冠军哟司机打卡 → 确认商业模式的正确性，心里有底气
  4. 第75章：资本翻车 → 意识到"专业性"比资本更重要
  5. 第120章：网络方案初步成形 → 从经营者升级为技术创新者
  6. 第150章：跨海隧道完全建立 + 乌蒙圈生态恢复 → 从行业推动者升级为**商业模式创新者**
  7. **第160章（新增）：决定回国开"音游窝"** → 从"日本创业者"升级为"国内创业者"
  8. **第180章：音游窝成型，父母看到成果** → **从"违背期望的冒险者"变成"被父母认可的创业者"**
- **终局定位**：从"乌蒙玩家"→"日本创业者"→"技术创新者"→**"国内音游商业模式开创者"**的四重身份转变
- **父母期望的反转**：
  - 开始：父母希望他在国内创业，他违背期望去日本
  - 中间：他在日本成功，但父母还是看不到
  - 终局：他带着日框、技术、经验回国，在国内建立"音游窝"——最终还是实现了"在国内创业"的目标，只是方式更宏大
- **单主角与搭档的分工冲突**：
  - 陈默：技术决策权、战略方向权，但频繁在商业细节上吃亏
  - 搭档：财务/运营决策权，但在技术创新上被动跟随
  - 冲突点：第50-60章的旅馆定价争议；第100-110章的扩张速度分歧；第165-175章的国内开店选址和资金分配
