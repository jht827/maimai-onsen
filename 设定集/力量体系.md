# 力量体系设定

## 体系公理
- **核心信条**："正确的技术选择 + 足够的执行力，能突破商业与规则的限制"。这不是虚幻的超能力，而是现实中可验证的技术知识
- **代价规则**：没有免费的午餐。技术突破需要投入（资金+时间+人力）。每次"聪明"的解决方案都会在其他环节付出代价
- **公平性原则**：
  - 任何人都可以学技术（但需要长时间投入）
  - 资本可以加速进程（但不能越过技术难度本身）
  - 陈默的"理工思维"是优势，但不是"无敌"（商业决策上他很菜）
  - 没有"越级"这回事；所有突破都是在"当前条件"下找最优解

## 体系类型
- **体系类型**：不是"修仙"或"异能"，而是"商业生态+硬件技术+网络工程"的现实体系
- **没有境界链**：没有"筑基""元婴"这种虚幻设定。进度用"项目阶段"和"技术成熟度"来标记
- **成熟度划分**（代替"小境界"）：
  1. **理论阶段**：概念存在，但未验证（第70-80章）
  2. **原型阶段**：小规模测试成功（第100-110章）
  3. **可部署阶段**：大规模运行可行（第130-150章）
  4. **稳定运营阶段**：市场化应用（第160-180章）

## 能力来源（不是"能量"，而是"能力"）
- **来源1：技术知识**
  - 网络工程（软路由、VPN配置、包转发）
  - 硬件维护（街机系统调试、电路诊断）
  - 系统运维（Linux、容器化部署、故障恢复）
  - 获取方式：学习、经验积累、团队合作
- **来源2：资本**
  - 陈默的300万人民币启动资金
  - 旅馆运营的利润积累
  - 获取方式：自有+商业融资（但故事里不涉及融资困难）
- **来源3：人脉**
  - 乌蒙圈玩家的信任和口碑
  - 日本方面的合作方（网络服务商、维修人员）
  - 获取方式：专业性展示+口碑传播
- **社会控制机制**：
  - 日本SEGA官方控制"机器发售权"（法人资质要求）
  - AllNet网络控制"合法连接权"（IP地址/网络环境检测）
  - 这两个限制无法直接突破，只能在限制框架内寻找漏洞

## 等级体系（改为"成就等级"）
不按"修为"而按"项目成就"来划分：

| 阶段 | 标志性成就 | 时间范围 | 核心能力 |
|------|-----------|---------|---------|
| L1 初级 | 获得日本法人身份+旅馆购置 | 第1-20章 | 资本决策、商业敏感度 |
| L2 中级 | 旅馆改造完成+首批客户稳定 | 第21-50章 | 项目管理、成本控制 |
| L3 高级 | 冠军代言+市场地位确立 | 第51-80章 | 品牌建设、竞争优化 |
| L4 精英 | 网络方案原型成功 | 第81-120章 | 深度技术整合 |
| L5 大师 | 跨海隧道完全部署 | 第121-180章 | 系统架构、行业推动 |

## 晋级条件
- **资源要求**：
  - L1→L2：需要足够的资本（购置旅馆）和时间（改造3-6个月）
  - L2→L3：需要高质量的客户体验和口碑累积
  - L3→L4：需要深入的技术研究投入（人力+时间）
  - L4→L5：需要国家级网络资源和团队规模（专业人才招募）
- **突破方式**：
  - 不是"闭关修炼"，而是"现实问题驱动"。每当遇到瓶颈，陈默就研究解决方案
  - 不允许"灵感一现就突破"。所有技术突破都需要20-50章的铺垫（代码查阅、硬件测试、方案验证）
- **失败代价**：
  - L1失败：损失启动资金+时间，项目流产
  - L2失败：旅馆改造出问题，客户流失，需要返工
  - L3失败：不会出现（一旦确立地位就很难翻车）
  - L4失败：网络方案不可行，需要重新研究（可能浪费1000万日元+）
  - L5失败：国内隧道不稳定，会被官方关闭（但故事里有备选方案）
- **"越级"的处理**：
  - 没有"越级突破"这种虚幻设定
  - 如果陈默想跳过某个阶段，会直接付出"时间不足导致基础不稳"的代价
  - 例：跳过L2（完全的旅馆磨合），直接进L3（冲刺市场），会在L3阶段遭遇"管理混乱"（实际发生过）

## 资源系统
- **核心资源类型**：
  1. **资本**（日元/人民币）：有上限且会逐步耗尽，需要靠运营利润补充
  2. **时间**（章数/月份）：网络基建搭建需要6-12个月，无法加速
  3. **技术知识**：陈默掌握，但也有上限（需要学习新领域）
  4. **人脉**：乌蒙圈玩家信任度、日本方面的合作关系
  5. **硬件**：街机机器（稀缺、昂贵）、网络设备（专线、光纤）
- **资源获取方式**：
  - 资本：启动资金（自有）+ 运营利润（旅馆月入）+ 贷款（故事里没有涉及）
  - 时间：按项目进度自然消耗
  - 技术知识：学习（论文+代码开源资源）+ 经验积累 + 团队协作
  - 人脉：口碑传播（冠军代言）+ 专业展示 + 媒体报道（后期）
  - 硬件：日本官方渠道（昂贵）+ 中古市场（便宜但风险高）
- **稀缺性规则**：
  - 正版日框：年产量有限，陈默竞争对手众多（后期资本跟风）
  - 国际光纤专线：全球性稀缺，报价天价，需要提前预约
  - 懂街机系统的运维：日本市场也缺人，陈默需要自主培养
  - 乌蒙圈玩家信任：一旦破裂很难恢复（这是陈默的底线）
- **替代路径/灰色交易**：
  - 正版框 ↔ 中古框：便宜但可能有隐藏故障，陈默后期采用"小比例中古"策略
  - 国际专线 ↔ VPN代理：VPN不稳定但便宜，陈默最终选择国际专线
  - 官方维修 ↔ 自主维修：陈默团队学会自主维修后可降低成本

## 战斗规则（改为"竞争规则"）
这不是"战斗"，而是"商业竞争"和"技术难度"

- **竞争对手**：
  1. **日本官方规则**：不是"敌人"，而是"约束条件"。陈默不能击败它，只能在限制内优化
  2. **资本跟风者**：有钱但不专业，陈默通过"细节优化"压制他们（例：隔音、按键调试、客户体验）
  3. **信息垄断者**（中古设备贩子）：陈默通过建立直接渠道来绕过
  4. **技术难度本身**：这是最难的"对手"，需要50-70章的研究才能突破

- **胜利条件**：
  - vs官方规则：在"合法框架内"找到最优解（后期的"合法欺骗"）
  - vs资本方：客户满意度和口碑胜过资本砸钱
  - vs技术难度：成功部署跨海隧道

- **失败风险**：
  - 被官方发现违法行为 → 被关闭
  - 资金耗尽 → 项目流产
  - 客户流失 → 口碑崩溃
  - 团队离散 → 技术方案中断

- **逃生/撤退机制**：
  - 如果日本方案失败，陈默有备选国家（台湾、东南亚等，但故事里没有探索）
  - 如果资金短缺，可以寻求国内风险投资（但陈默很抗拒这个选项）
  - 如果客户不满意，可以进行产品迭代（例：加强隔音、更新设备配置等）

## 禁忌与限制
- **硬限制（绝不能触犯）**：
  - ❌ 不能直接破解bytelocker（违反DMCA等国际版权法）
  - ❌ 不能在日本没有法人身份的情况下购买机器
  - ❌ 不能明目张胆地绕过AllNet网络检测（官方会直接断线）
  - ❌ 不能损害乌蒙圈的利益（这是陈默的底线）

- **灰色地带（可以智慧利用）**：
  - ✓ 在规则框架内找"漏洞"（例：网络延迟检测不到位 → 可以延迟转发数据包）
  - ✓ 用"技术迂回"替代"直接突破"（例：不破解机器，改为让机器相信自己在日本）
  - ✓ 利用市场信息不对等（例：资本方不懂行业细节，被陈默的专业性压制）

- **高阶限制**：
  - 陈默的技术能力有天花板（某些日本官方的特殊加密手段他无法突破）
  - 国际网络是全球管制的（不能随意干扰他国网络）
  - 商业决策的风险是真实的（资金亏损、人心背离都是可能）

## 体系漏洞与利用
- **核心漏洞1：AllNet网络的"地理检测"逻辑**
  - 漏洞描述：AllNet VPN检测机器位置时，只检查"IP源头"和"网络延迟"，不检查"真实物理位置"
  - 陈默如何利用：通过三河安城的日本端点和软路由转发，让国内机器的数据包"看起来"来自三河安城
  - 风险：一旦官方升级检测算法（例：增加硬件认证），这个漏洞就失效了（故事里有隐约的暗示）

- **核心漏洞2：商业规则的"灰度"**
  - 漏洞描述：日本官方规定"只卖给法人"，但不规定"法人必须是大公司"。一个一人法人企业依然合法
  - 陈默如何利用：以三河安城旅馆的合法法人身份购买机器，然后通过"改良但不破解"的方式运营

- **核心漏洞3：资本方的"信息盲点"**
  - 漏洞描述：资本方看到陈默成功后，迅速复制模式，但忽视了"细节优化"（隔音、按键调试、运维能力）
  - 陈默如何利用：持续打磨产品细节，让竞品无法跟进
  - 结果：资本方翻车，陈默确立垄断地位

- **故事保险：备选漏洞**
  - 如果AllNet漏洞被发现，陈默有第二套方案：国内专线直连（成本更高，但更隐蔽）
  - 这个备选方案在第150章左右有铺垫，但不会被实际使用（因为第一套方案成功了）
